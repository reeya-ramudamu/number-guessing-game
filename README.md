
# 🎯 Number Guessing Game

A fully interactive **Number Guessing Game** built using **JavaScript, jQuery, and Session Storage**.

This project demonstrates core JavaScript programming concepts by combining logic, DOM manipulation, event handling, and browser storage into a real-world mini application.

---

## 📌 Project Overview

The game generates a random number between **1 and 100**.  
The player must guess the correct number, and the game provides feedback:

- 📉 Too Low  
- 📈 Too High  
- 🎉 Correct Guess  

The game also tracks:

- ✅ Number of attempts  
- 🏆 Best score  
- 🎮 Total games played  
- 📜 Guess history  
- 💾 Session storage persistence  

---

## 🚀 Live Features

- Random number generation
- Input validation
- Attempt counter
- Guess history display
- Best score tracking
- Games played tracking
- Session storage persistence
- Dynamic DOM updates using jQuery
