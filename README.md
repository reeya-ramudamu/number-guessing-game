
# 🎯 Number Guessing Game

A fully interactive **Number Guessing Game** built using **JavaScript, jQuery, and Session Storage**.

This project demonstrates core JavaScript programming concepts by combining logic, DOM manipulation, event handling, and browser storage into a real-world mini application.

---

## 📌 Project Overview

The game generates a random number between **1 and 100**.  
The player must guess the correct number, and the game provides feedback:

- 📉 Too Low  
- 📈 Too High  
- 🎉 Correct Guess  

The game also tracks:

- ✅ Number of attempts  
- 🏆 Best score  
- 🎮 Total games played  
- 📜 Guess history  
- 💾 Session storage persistence

## 🚀 Features

- 🎲 Random number generation  
- 📊 Tracks attempts and guess history  
- 🏆 Best score tracking  
- 🎮 Games played counter  
- 💾 Session storage persistence  
- ✅ Input validation to prevent duplicates and out-of-range numbers  
- ✨ Dynamic feedback: Too High, Too Low, Correct Guess  
- 🔄 Reset game and clear stats functionality  
---

## 🛠️ Technologies Used

- **HTML5** – Structure and layout  
- **CSS3** – Styling and responsiveness  
- **JavaScript (ES6)** – Game logic  
- **jQuery (v3.7.1)** – DOM manipulation and event handling  
- **Session Storage** – Persistent game statistics
